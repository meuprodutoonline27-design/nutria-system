2. Como instalar no celular

Android · Chrome

  1. Abra o link do NutriIA no Chrome.
  2. Toque nos três pontos do menu.
  3. Escolha “Adicionar à tela inicial” ou “Instalar aplicativo”.
  4. Confirme e abra o novo ícone.

iPhone · Safari

  1. Abra o link do NutriIA no Safari.
  2. Toque no botão de compartilhar.
  3. Escolha “Adicionar à Tela de Início”.
  4. Confirme e abra o novo ícone.

3. Como usar

  1. Informe o nome do profissional e escolha a cor da marca.
  2. Preencha peso, altura, idade, objetivo e restrições do paciente.
  3. Clique em “Gerar Cardápio da Semana”.
  4. Revise as refeições e a lista de compras.
  5. Use “Enviar por WhatsApp” para abrir a mensagem pronta e escolher o contato.
  6. Consulte o histórico para restaurar cardápios anteriores.

4. Como baixar o código-fonte

  1. Abra o repositório do GitHub pelo link desta página.
  2. Clique no botão verde Code.
  3. Escolha Download ZIP.
  4. Extraia o arquivo ZIP no computador.
  5. Abra index.html para visualizar o app.
